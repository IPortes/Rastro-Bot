# Rastro Bot V2

Cliente comercial para PStory com portal de conta, selecao de jogo e atualizacao automatica segura.

## Download

Baixe sempre o pacote de instalacao inicial na release estavel:

- [Rastro Bot V2 - download oficial](https://github.com/IPortes/Rastro-Bot/releases/tag/rastro-v2-stable)

O launcher consulta esse mesmo canal para receber novas versoes. As atualizacoes usam manifesto RSA assinado, SHA-256, validacao de tamanho, staging, rollback e verificacao de inicializacao.

O codigo-fonte e as chaves privadas nao fazem parte deste repositorio de distribuicao.
